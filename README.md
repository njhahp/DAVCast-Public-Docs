# DAVCast App Store Materials

This repository contains public App Store submission and review materials for DAVCast.

Included documents:

- Privacy-Policy.md
- Support.md
- Terms-of-Use.md
- Submission-Checklist.md
- App-Store-Connect-Metadata.md

GitHub Pages files are also included under `docs/` so the privacy policy, support page, and terms can be shared as public URLs for App Store Connect.

Recommended public URLs:

- Home: https://njhahp.github.io/DAVCast-AppStore-Materials/
- Support: https://njhahp.github.io/DAVCast-AppStore-Materials/support
- Privacy Policy: https://njhahp.github.io/DAVCast-AppStore-Materials/privacy-policy
- Terms of Use: https://njhahp.github.io/DAVCast-AppStore-Materials/terms

This repository intentionally excludes application source code.
