# DAVCast Public Docs

This repository contains the public App Store materials for DAVCast.

Included documents:

- Privacy-Policy.md
- Support.md
- Terms-of-Use.md
- Submission-Checklist.md
- App-Store-Connect-Metadata.md

GitHub Pages files are included under `docs/` so the privacy policy, support page, and terms can be shared as public URLs for App Store Connect.

Recommended public URLs:

- Home: https://njhahp.github.io/DAVCast-Public-Docs/
- Support: https://njhahp.github.io/DAVCast-Public-Docs/support
- Privacy Policy: https://njhahp.github.io/DAVCast-Public-Docs/privacy-policy
- Terms of Use: https://njhahp.github.io/DAVCast-Public-Docs/terms

This repository intentionally excludes application source code.
