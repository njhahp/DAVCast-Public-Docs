# DAVCast App Store Connect Metadata

This page summarizes the release metadata prepared for DAVCast. The editable source version remains in `docs/AppStore/App-Store-Connect-Metadata.md`.

Current product positioning used in metadata:

- DAVCast is a WebDAV file manager and media browser
- Core file actions include upload, download, create folder, rename, move, and delete
- Upload supports local files, Photos export, and Music Library selection (`MPMediaPicker`)
- Unreadable tracks (DRM/cloud-only/system-restricted) are skipped with explicit user warnings

- Support URL: `https://njhahp.github.io/DAVCast-Public-Docs/support`
- Privacy Policy URL: `https://njhahp.github.io/DAVCast-Public-Docs/privacy-policy`
- Terms of Use URL: `https://njhahp.github.io/DAVCast-Public-Docs/terms`
