# DAVCast Support

DAVCast helps you connect to WebDAV servers, browse and manage files (upload/download/create folder/rename/move/delete), play media, preview documents, manage playlists and favorites, and cast supported content through AirPlay or DLNA.

## What DAVCast supports

- WebDAV server connection and browsing
- WebDAV file management: upload, download, create folder, rename, move, delete
- Video and audio playback
- Image, PDF, text, Markdown, HTML, and Office document preview
- AirPlay and DLNA casting on supported networks and devices
- Playlist and favorites management
- Subscription purchase, restore, and entitlement refresh through the App Store

## Common troubleshooting

### WebDAV connection fails

- Verify the server URL, path, username, and password
- Confirm the server is reachable from the current network
- Test with a small file first to confirm permissions

### A file does not play or preview correctly

- Verify the file itself is valid
- Verify the file format or codec is supported by the device or route
- Test the same file with another compatible player if needed

### No AirPlay or DLNA device appears

- Confirm DAVCast has Local Network permission
- Confirm the playback target is online and on the same network
- Wait a few seconds and retry discovery

### Subscription access is missing

- Open Settings in DAVCast
- Use Restore Purchases
- Confirm the App Store account matches the purchase account
