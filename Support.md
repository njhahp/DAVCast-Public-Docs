# DAVCast Support

DAVCast helps you connect to WebDAV servers, browse files, play media, preview documents, manage playlists and favorites, and cast supported content through AirPlay or DLNA.

## What DAVCast supports

- WebDAV server connection and browsing
- Video and audio playback
- Image, PDF, text, Markdown, HTML, and Office document preview
- AirPlay and DLNA casting on supported networks and devices
- Playlist and favorites management
- Subscription purchase, restore, and entitlement refresh through the App Store

## Before contacting support

Check these common points first:

- Verify the WebDAV server URL, path, username, and password
- Confirm the server is reachable from the device network
- Test with a small file first to confirm permissions and connectivity
- Make sure the playback target and the device are on the same local network for AirPlay or DLNA
- If a subscription is missing, try Restore Purchases from Settings

## Common troubleshooting

### WebDAV connection fails

- Re-check the server URL and path
- Re-check account credentials
- Confirm the server exposes WebDAV correctly
- Confirm the server is reachable over the current network

### A media file does not play

- Verify the file itself is valid
- Verify the file format or codec is supported by the device or target playback route
- Test the same file locally or on another compatible player

### No cast device is visible

- Confirm the device granted Local Network permission to DAVCast
- Confirm the playback target is online and on the same network
- Wait a few seconds and retry device discovery

### Subscription access is missing

- Open Settings in DAVCast
- Use Restore Purchases
- Confirm the App Store account matches the purchase account
